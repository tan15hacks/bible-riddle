# Store listing draft

## App name

Bible Riddle

## Short description

A peaceful offline Bible riddle game for learning scripture through simple daily challenges.

## Full description draft

Bible Riddle is a calm, minimalist Bible trivia and riddle game designed for short, meaningful play sessions. Choose Old Testament or New Testament campaigns, answer Bible-based riddles, use optional hints, earn stars and coins, and learn from short explanations with scripture references.

The core game is designed to work offline. Ads, purchases, analytics, and cloud features are optional future additions and are not required for core progression.
