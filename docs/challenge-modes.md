# Challenge modes

Challenge modes are planned after the storage migration.

## Planned modes

- Ten-question challenge
- Old Testament challenge
- New Testament challenge
- Endless mode with three hearts
- Speed mode with a 60-second timer
- Mistake review
- Mixed Testament challenge

## Storage needs

Challenge scores should be stored in SQLite under `player_statistics_rows.challenge_scores_json` or split into a dedicated table in a later migration if score history becomes complex.
