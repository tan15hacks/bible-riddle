# Accessibility

Phase B keeps accessibility requirements visible for later implementation.

## Current direction

- Minimalist UI with readable text
- Non-blocking game flow
- No forced ads or paid blockers

## Required before release

- Screen-reader labels for interactive elements
- Large text testing
- Color-independent feedback
- Reduced-motion support
- Adequate touch targets
- Haptic and audio toggles
- Text scaling without clipping
- Keyboard navigation where relevant

Gameplay feedback must not rely only on red/green color.
