# Daily riddle

Daily riddle logic is not active in Phase B.

## Future offline mode

- Select from an approved non-spoiler pool.
- Use local date to choose a deterministic riddle.
- Store completion by calendar date.
- Award a daily bonus only once per date.

## Future online mode

- Allow remote configuration.
- Cache the selected riddle.
- Fall back to offline mode when remote content is unavailable.
- Avoid repeating daily riddles within a configured window.
