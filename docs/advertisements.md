# Advertisements

No advertisements are active in Phase B.

Future rewarded ads must remain optional and must never block core progression, Bible references, explanations, or level continuation.

Allowed future placements:

- Optional hint reward
- Optional reward multiplier
- Optional challenge second chance
- Optional small coin reward

Disallowed placements:

- Forced interstitials
- Startup ads
- Ads before explanations or Bible references
- Ads disguised as Continue, Next, Submit, or Claim buttons

Production AdMob IDs must be supplied through environment configuration or Dart defines, not committed to the repository.
