# Google Play checklist

Phase B is not release-ready yet. Use this checklist later in the release phase.

## Technical

- Android application ID finalized
- App icons and adaptive launcher icon configured
- Release signing configured locally
- R8/ProGuard reviewed
- App Bundle builds successfully
- Internal testing track completed

## Policy

- Privacy policy URL ready
- Data Safety form completed
- Ads declaration completed if ads are enabled
- Content rating questionnaire completed
- Target audience and children policy reviewed

## Content

- Production riddle pack marked `reviewed`
- Content validation has zero critical errors
- Bible translation notice included
- Content issue reporting path available

## Store assets

- Short description
- Full description
- Feature graphic
- Phone screenshots
- Tablet screenshots if targeting tablets
