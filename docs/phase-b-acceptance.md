# Phase B acceptance

Phase B is acceptable when:

- Drift dependencies are present.
- Drift schema exists for all required local tables.
- Repository contracts exist for content and progress.
- Content import is blocked when critical validation errors exist.
- CSV import tooling exists.
- Documentation explains database, import, validation, privacy, testing, and release concerns.
- The Phase A playable loop is not broken intentionally.

Flutter validation still needs to be run in a local Flutter environment.
