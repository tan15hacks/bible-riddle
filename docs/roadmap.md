# Roadmap

## Phase A — Complete

Playable offline loop with bundled riddles, basic progression, hints, coins, stars, progress screen, settings reset, and validation script.

## Phase B — Current

Drift schema, repository contracts, content import gate, CSV import tool, and documentation.

## Phase C — Next

Wire the runtime app to Drift/SQLite, migrate SharedPreferences progress, add achievement persistence, daily riddle persistence, and richer statistics.

## Phase D

Challenge modes: ten-question challenge, testament challenges, endless mode, speed mode, mistake review, and mixed testament challenge.

## Phase E

Optional rewarded ads, purchase abstraction, privacy controls, accessibility polish, expanded tests, 1,000+ reviewed content pipeline, and Google Play release prep.
