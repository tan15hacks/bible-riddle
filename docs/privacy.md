# Privacy

Phase B does not add online accounts, analytics, ads, purchases, or cloud synchronization.

## Current data stored locally

- Level progress
- Coins and basic statistics
- Settings and onboarding state
- Future Drift tables for profile, achievements, daily riddles, purchases, and app settings

## Data not collected

- Religious affiliation
- Sensitive religious beliefs
- Exact location
- Contacts
- Raw typed answers for analytics

## Future requirements

Before enabling analytics, ads, purchases, notifications, or cloud sync, add opt-out controls, consent handling where required, and a production privacy policy URL for Google Play.
